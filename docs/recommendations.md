# Рекомендации

## Назначение

Модуль рекомендаций подбирает упражнения под профиль пользователя, доступное оборудование, ограничения, недавнюю историю и цели. Результат используется на странице рекомендаций и в генераторе тренировки.

Основные файлы:

- `js/features/recommendations.js`;
- `js/features/workout-generation.js`;
- `js/features/exercise-compatibility.js`;
- `js/features/contraindications.js`;
- `js/features/body-focus.js`.

## Два этапа

Рекомендации строятся в два этапа:

1. Жесткая фильтрация кандидатов.
2. Взвешенный скоринг оставшихся упражнений.

Такой подход не дает опасным или недоступным упражнениям попасть в выдачу даже при высоком совпадении по целям.

## Жесткая фильтрация

`filterExercisesForRecommendations()` исключает упражнения по причинам:

| Код | Причина |
| --- | --- |
| `duplicate-exercise-id` | Нет ID или ID уже встречался. |
| `missing-required-equipment` | Требуется недоступное оборудование. |
| `difficulty-above-profile-level` | Сложность выше уровня пользователя. |
| `goal-not-matched` | Цель не совпала при `goalMode: "require"`. |
| `contraindication-match` | Совпадение с ограничениями профиля. |
| `excluded-exercise` | Упражнение явно исключено. |

Фильтрация возвращает eligible и excluded списки, а также summary с количеством исключений по причинам.

## Скоринг

`rankExercisesForRecommendations()` вызывает `scoreExercise()` для каждого eligible-упражнения и сортирует результат по убыванию score.

Дефолтные веса:

| Компонент | Вес |
| --- | ---: |
| `goalAlignment` | 0.32 |
| `difficultyFit` | 0.14 |
| `equipmentFit` | 0.05 |
| `movementFocus` | 0.14 |
| `movementVariety` | 0.10 |
| `contraindicationsFit` | 0.15 |
| `preferenceFit` | 0.04 |
| `recoveryFit` | 0.04 |
| `timeFit` | 0.02 |

Итоговый score ограничен диапазоном от 0 до 1.

## Сигналы скоринга

`goalAlignment` учитывает цели профиля: сила, гипертрофия, выносливость, снижение веса, мобильность и general fitness.

`difficultyFit` сравнивает сложность упражнения с уровнем пользователя.

`equipmentFit` проверяет выбранное оборудование. `bodyweight` добавляется как базовое доступное оборудование.

`movementFocus` сопоставляет приоритеты зон тела с основными и вторичными мышцами упражнения.

`movementVariety` снижает оценку за упражнения и паттерны движения из недавней истории.

`contraindicationsFit` дает 0 при совпадении противопоказаний.

`preferenceFit` учитывает нелюбимые упражнения и понравившиеся теги.

`recoveryFit` сопоставляет основные мышцы упражнения с профилем восстановления.

`timeFit` сравнивает примерную длительность упражнения с целевой длительностью сессии.

## Объяснение результата

Для каждого упражнения возвращаются:

- `reasons` - человекочитаемые причины;
- `matchedSignals` - совпавшие сигналы;
- `penalties` - штрафы;
- `parts` - вклад каждого компонента.

Эти поля полезны для UI и отладки.

## Генерация тренировки

`createSingleWorkoutRecommendation()` строит готовую тренировку поверх рекомендаций.

Входные параметры:

- список упражнений;
- профиль;
- оборудование;
- request с длительностью, типом и приоритетами;
- исключенные упражнения;
- настройки goal mode и weights.

Типы тренировки:

- `auto`;
- `straight`;
- `circuit`;
- `interval`;
- `mobility`.

Если выбран `auto`, тип определяется по доминирующей цели и длительности:

- мобильность - `mobility`;
- снижение веса или выносливость - `interval` для коротких сессий или `circuit` для длинных;
- остальные случаи - `straight`.

## Слоты тренировки

Генератор создает шаблон слотов:

- разминка;
- основные силовые упражнения;
- аксессорные упражнения;
- корпус;
- кондиционная работа;
- финишер;
- мобильность.

Для каждого слота выбирается уникальное упражнение. Оценка выбора учитывает:

- рекомендационный score;
- соответствие типу и тегам слота;
- разнообразие паттернов движения;
- fit роли слота.

## Назначение объема

`prescribeWorkoutItem()` назначает:

- количество подходов;
- повторы или длительность;
- отдых между подходами;
- отдых после упражнения.

Объем зависит от:

- роли слота;
- типа тренировки;
- доминирующей цели;
- уровня подготовки;
- режима выполнения упражнения.

## Подгонка под длительность

`fitWorkoutToDuration()` сравнивает расчетную длительность с целью и корректирует объем:

- если тренировка слишком длинная, уменьшает подходы, длительность или убирает хвостовые элементы;
- если слишком короткая, увеличивает подходы или длительность;
- целевой допуск - 12%.

Минимальная длительность запроса - 10 минут, максимальная - 120 минут.

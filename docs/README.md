# Документация Workout Planner

Workout Planner - статическое PWA-приложение для составления, запуска и учета персональных тренировок. Проект работает без фронтенд-фреймворка: интерфейс собран на HTML, CSS и ES-модулях, данные хранятся локально в браузере, а офлайн-запуск обеспечивается service worker.

## Быстрый старт

Требования:

- Node.js 22+
- современный браузер с поддержкой ES modules, service workers, `localStorage`, Web Audio API и File API

Установка зависимостей:

```bash
npm ci
```

Запуск локального статического сервера:

```bash
npx serve .
```

Альтернатива:

```bash
python -m http.server 8000
```

Открывать приложение через `file://` не рекомендуется: маршрутизация и service worker рассчитаны на `localhost`, `127.0.0.1` или HTTPS.

## Основные возможности

- каталог встроенных и пользовательских упражнений;
- фильтры, избранное, нежелательные упражнения и совместимость с профилем;
- ручной конструктор тренировок;
- генерация одной тренировки под цель, длительность, оборудование и ограничения;
- пошаговый запуск тренировки с таймером, отдыхом, паузой, пропуском и восстановлением активной сессии;
- история, статистика и календарь активности;
- настройки профиля, оборудования, темы, языка, плотности интерфейса и звуков;
- локальный JSON-импорт и экспорт.

## Основные команды

| Команда | Назначение |
| --- | --- |
| `npm test` | Запуск Jest-тестов. |
| `npm run coverage` | Тесты с проверкой покрытия. |
| `npm run e2e` | Smoke-тесты Playwright. |
| `npm run lint` | Проверка ESLint. |
| `npm run format:check` | Проверка форматирования Prettier. |
| `npm run generate:precache` | Обновление precache-списка в `sw.js`. |

## Где искать код

| Путь | Назначение |
| --- | --- |
| `index.html` | Статический app shell. |
| `js/app.js` | Bootstrap приложения. |
| `js/core/` | Роутер, состояние, PWA-регистрация и общие утилиты. |
| `js/features/` | Доменная логика упражнений, рекомендаций, тренировок и истории. |
| `js/pages/` | Рендереры экранов и переиспользуемые компоненты страниц. |
| `js/session/` | Движок активной тренировки. |
| `js/storage/` | Схема, миграции, репозитории и фасад хранилища. |
| `js/ui/` | UI-действия, обработчики событий и оболочка приложения. |
| `data/` | Исходные JSON-справочники. |
| `styles/` | CSS по областям приложения. |
| `tests/` | Модульные, интеграционные и e2e-тесты. |

# Движок тренировочной сессии

## Назначение

Движок сессии отвечает за пошаговый запуск тренировки: упражнения, отдых между подходами, отдых между упражнениями, таймер, паузу, пропуск, изменение времени, звуковые сигналы и восстановление после закрытия вкладки.

Основные файлы:

| Файл | Назначение |
| --- | --- |
| `js/session/model.js` | Статусы, фазы, типы шагов, tempo-константы. |
| `js/session/steps.js` | Построение шагов из тренировки. |
| `js/session/core.js` | Контроллер `WorkoutSession`. |
| `js/session/snapshot.js` | Сохранение и восстановление активной сессии. |
| `js/session/hooks.js` | Нормализация callbacks. |
| `js/session/ui.js` | Связь с DOM. |
| `js/session/ui-format.js` | Форматирование значений для UI. |

## Статусы

Сессия поддерживает статусы:

- `idle` - создана, но не запущена;
- `running` - таймер идет;
- `paused` - таймер остановлен, сессия может быть продолжена;
- `completed` - тренировка завершена;
- `aborted` - тренировка прервана.

Восстановить можно только `running` и `paused`.

## Фазы

Основные фазы:

- `exercise`;
- `rest-between-sets`;
- `rest-between-exercises`;
- `finished`.

Для упражнений с повторами движок может дополнительно вычислять фазу внутри повторения по tempo:

- `eccentric`;
- `pauseBottom`;
- `concentric`;
- `pauseTop`.

Дефолтный tempo одного повторения - 3 секунды: 1 секунда эксцентрика, 1 секунда пауза внизу, 1 секунда концентрика, 0 секунд пауза вверху.

## Построение шагов

`buildWorkoutSteps(workout, exercises)`:

1. нормализует тренировку;
2. строит карту упражнений;
3. проходит по элементам тренировки;
4. для каждого подхода добавляет exercise-step;
5. между подходами добавляет rest-between-sets;
6. между упражнениями добавляет rest-after-exercise.

Шаг упражнения содержит:

- ID workout item;
- ID упражнения;
- индекс упражнения и подхода;
- количество подходов;
- режим выполнения;
- повторы, длительность, дистанцию и заметки;
- расчетное усилие `effort`.

## Режимы выполнения

Поддерживаются:

- `reps` - длительность считается как `reps * repDurationSec`;
- `time` - используется `durationSec`;
- `hold` - используется `durationSec`;
- `custom` - fallback для нестандартных случаев.

Если упражнение содержит `executionMode`, он имеет приоритет. Если режима нет, движок выводит его из `reps` или `durationSec` workout item.

## Контроллер WorkoutSession

Создание:

```js
const session = createWorkoutSession(workout, exercises, options);
session.start();
```

Основные методы:

| Метод | Поведение |
| --- | --- |
| `start()` | Запускает сессию и таймер. |
| `pause()` | Ставит на паузу. |
| `resume()` | Продолжает после паузы. |
| `skipCurrentStep()` | Переходит к следующему шагу. |
| `addTime(seconds)` | Добавляет время к текущему шагу. |
| `subtractTime(seconds)` | Уменьшает время текущего шага. |
| `abort()` | Прерывает тренировку и удаляет снимок. |
| `tick()` | Уменьшает остаток на 1 секунду и двигает прогресс. |
| `getSnapshot()` | Возвращает полное состояние для UI. |

## Снимок состояния

`getSnapshot()` возвращает:

- статус и фазу;
- тренировку;
- список шагов;
- текущий шаг;
- индекс текущего шага;
- прошедшее и оставшееся время;
- общую длительность;
- прогресс;
- время старта и окончания.

Этот объект удобен для рендера, но в `localStorage` сохраняется сокращенная версия.

## Persisted snapshot

Сокращенный снимок включает:

- `version`;
- `savedAt`;
- `status`;
- `workout`;
- `steps` с ID и длительностью;
- `currentStepIndex`;
- `remainingSec`;
- `elapsedSec`;
- `startedAt`.

Снимок сохраняется принудительно при важных действиях и периодически во время работы. Дефолтный интервал сохранения - 5000 мс.

## Восстановление

`restoreWorkoutSession(snapshot, exercises, options)`:

1. нормализует снимок;
2. создает новую `WorkoutSession` из сохраненной тренировки;
3. проверяет, что количество шагов совпадает;
4. проверяет, что ID шагов совпадают;
5. проверяет корректность `remainingSec`;
6. восстанавливает статус, индекс, длительности и elapsed;
7. при статусе `running` запускает таймер, если `autoStartTimer !== false`.

Если восстановление невозможно, снимок удаляется.

## Звуковые события

Движок вызывает `playSignal()` для событий:

- начало упражнения;
- начало отдыха;
- конец отдыха;
- завершение упражнения;
- смена фазы повторения;
- завершение тренировки.

Звук можно отключить через `options.audio === false` или пользовательские настройки.

## Хуки

Через options передаются callbacks:

- `onTick`;
- `onStepChange`;
- `onPhaseChange`;
- `onWorkoutComplete`;
- `onWorkoutAbort`.

Хуки позволяют UI обновляться без смешивания DOM-логики с таймером.

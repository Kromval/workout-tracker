# Скриншоты

## Назначение

Этот файл фиксирует список экранов, которые стоит поддерживать в актуальном виде для README, презентаций, релизов и ручной проверки интерфейса.

В репозитории сейчас нет обязательного каталога со скриншотами. Рекомендуемый путь для файлов:

```text
docs/screenshots/
```

или, если нужно отделить бинарные assets от Markdown:

```text
assets/screenshots/
```

## Правила обновления

Обновляйте скриншоты, если:

- изменился layout основного экрана;
- добавлена или удалена важная функция;
- изменились тексты навигации;
- изменились состояния рекомендаций, генератора или сессии;
- обновлена тема, плотность или визуальный стиль.

## Подготовка данных

Для стабильных скриншотов используйте отдельный профиль браузера или очищенный `localStorage`.

Минимальный demo-набор:

- заполненный профиль;
- выбранное оборудование;
- несколько избранных упражнений;
- одна пользовательская тренировка;
- одна запись истории;
- активная тренировка для экрана сессии.

## Ручной сценарий съемки

1. Запустите приложение:

   ```bash
   npx serve .
   ```

2. Откройте URL из терминала.
3. Подготовьте demo-данные.
4. Перейдите на нужный route.
5. Сделайте скриншот desktop viewport.
6. Повторите для мобильного viewport, если экран критичен для мобильного UX.

## Рекомендованные размеры

- Desktop: 1440 x 1000.
- Mobile: 390 x 844.

Используйте один и тот же масштаб браузера, чтобы изображения не отличались плотностью текста.

## Проверка перед публикацией

Перед добавлением скриншотов убедитесь:

- нет персональных данных;
- нет случайных devtools или системных уведомлений;
- состояние интерфейса воспроизводимо;
- активная сессия не перекрывает важные элементы;
- русская и английская локализация не смешаны на одном экране без причины.

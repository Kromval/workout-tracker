| `use-cases-mvp.mmd` | Диаграмма вариантов использования | Раздел 5.1 |
| `app-architecture.mmd` | Общая архитектура приложения | Раздел 7.1 |
| `app-bootstrap-flow.mmd` | Поток запуска приложения | Раздел 7.2 |
| `modules-layers.mmd` | Диаграмма слоев и модулей | Раздел 7.3 |
| `localstorage-data-model.mmd` | Модель данных `localStorage` | Раздел 8.1 |
| `entity-relations.mmd` | Связь сущностей | Разделы 8.3-8.4 |
| `workout-generation-algorithm.mmd` | Алгоритм генерации тренировки | Раздел 10.3 |
| `workout-session-states.mmd` | Состояния тренировочной сессии | Раздел 11.2 |
| `workout-steps-transformation.mmd` | Преобразование тренировки в шаги | Раздел 11.1 |
| `pwa-cache-flow.mmd` | PWA cache flow | Раздел 13.2 |
| `testing-ci.mmd` | Схема тестирования и CI | Раздел 14.1 или 14.4 |

# FAQ

## Где хранятся мои данные?

В `localStorage` браузера под ключом `workout-tracker:data`. Данные не отправляются на сервер.

## Можно ли перенести данные на другое устройство?

Да. Сделайте экспорт JSON в настройках, затем импортируйте файл на другом устройстве или в другом браузере.

## Почему приложение не работает через `file://`?

Service worker, ES-модули и часть browser API ожидают запуск через HTTP(S). Для разработки используйте `npx serve .` или `python -m http.server 8000`.

## Почему офлайн-режим не включился сразу?

Первый запуск должен пройти онлайн, чтобы service worker установился и закешировал app shell. После этого перезагрузите страницу и проверьте офлайн-режим.

## Что делать, если после изменений приложение показывает старую версию?

Обновите страницу. Если проблема сохраняется, удалите service worker и кеш сайта в DevTools. Для разработки после изменения статических файлов выполните `npm run generate:precache`.

## Как добавить новые встроенные упражнения?

Отредактируйте `data/exercises.json`, затем выполните:

```bash
node scripts/generate-exercises-data.js
npm test -- tests/features/exercise-data-tags.test.js
```

Если изменился app shell, обновите precache:

```bash
npm run generate:precache
```

## Почему упражнение не попало в рекомендации?

Возможные причины:

- нет нужного оборудования;
- сложность выше уровня профиля;
- упражнение совпало с противопоказаниями;
- оно явно исключено;
- включен строгий режим цели и цель не совпала;
- ID упражнения дублируется.

## Как рекомендации считают оценку?

Оценка строится из нескольких частей: цели, сложность, оборудование, фокус тела, разнообразие, противопоказания, предпочтения, восстановление и длительность. Итог ограничен диапазоном от 0 до 1.

## Почему генератор выбрал не тот тип тренировки?

Если выбран `auto`, тип зависит от доминирующей цели и длительности. Мобильность дает `mobility`, снижение веса и выносливость дают `interval` или `circuit`, остальные цели чаще дают `straight`.

## Можно ли восстановить тренировку после закрытия вкладки?

Да, если сессия была в статусе `running` или `paused`, а структура тренировки не изменилась. После завершения или прерывания снимок удаляется.

## Почему восстановление сессии не сработало?

Снимок удаляется, если он поврежден, относится к завершенной сессии, содержит неверное время или список шагов больше не совпадает с текущей тренировкой.

## Как включить пользовательские звуки?

В настройках включите звук, задайте громкость и загрузите аудиофайлы для нужных событий. Поддерживаются audio Data URL с MIME-типами MP3, WAV и OGG.

## Как сбросить данные?

Используйте сброс в настройках, если он доступен в UI, или очистите данные сайта в браузере. Перед сбросом сделайте экспорт, если данные нужны.

## Какие браузеры поддерживаются?

Современные браузеры с поддержкой ES modules, service workers, `localStorage`, Web Audio API и File API.

## Что делать разработчику перед pull request?

Запустите:

```bash
npm run lint
npm run format:check
npm test
npm run e2e
npm run coverage
```
